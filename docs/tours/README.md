# Tours

A history of finished work, shown rather than described. After each bigger
piece of work, run the system and write one tour. Open `index.html` in a
browser to see them all.

Each tour is one self-contained HTML file named `YYYY-MM-DD-<topic>.html`,
linked at the top of the list in `index.html`. Copy the newest tour as a
starting point, so they all look alike. A tour has:

- a diagram of what was built and where it sits in the system;
- the steps of the code as it runs, each with its file and line;
- real output from running it (counts, sample rows, logs), with the date of
  the run;
- what the data shows, and the decisions still open;
- the commands to run it yourself.

Tours are snapshots: don't update old ones when the code changes.
